# premusic 사용 이력

Pixabay에서 받은 premusic 원본 중 평가에 사용한 81곡을 용도별로 옮겼습니다. `usage_manifest.csv`에 이전 위치, 현재 위치, SHA-256, 사용한 평가를 기록했습니다. 한 곡은 2026-10-23 진단과 2026-10-24 AI 표시군 진단에 모두 사용돼 사용 이력이 두 개입니다.

- `fresh_audit_20261023/`: 이전 정상후보 진단 30곡
- `ai_labeled_diagnostic_20261024/`: 이전 AI 표시군 진단에서만 사용한 1곡
- `premusic_holdout_20261029/`: 이번 신규 정상후보 진단 50곡

premusic에서 제거한 중복 파일 78개는 원곡·music·이 폴더 또는 남은 premusic에 바이트 단위로 동일한 보존본이 있습니다. 각 삭제 파일과 보존본의 경로는 `reorganization_plan_20261029.json`에 있습니다. 과거 평가 manifest의 원래 경로는 연구 기록으로 남겼으며, 재현 시 이 대응표로 현재 파일을 찾으세요.

Pixabay 다운로드 출처만으로 AI 생성 여부가 입증되지는 않습니다.
