# Layer 2 시험 데이터 안내

각 폴더의 manifest.csv는 쿼리, 원곡 출처, 변형 방식을 연결합니다. 평가 시 같은 원곡의 변형을 튜닝과 홀드아웃에 나눠 넣지 않도록 출처별로 그룹을 분리합니다.

| 폴더 | 쿼리 수 | 내용 | 한계 |
|---|---:|---|---|
| plagiarism_positive/ | 90 | 동일 녹음 발췌·재인코딩·속도·피치·효과 변형 | 독립 연주 아님 |
| reperformed_positive/ | 30 | 10개 원곡의 section edit, tempo/pitch/EQ, remix FX 자동 변형 | 이름과 달리 사람이 재연주하지 않음 |
| safe_arranged/ | 30 | 10개 출처의 편집/효과 정상 대조 후보 | 전문가 검증된 비표절 라벨 아님 |
| synthetic_layered_positive/ | 10 | 원곡 위에 합성 패드·베이스·퍼커션 추가 | 원곡이 계속 들리는 인공 믹스 |

## 평가 시 유의사항

- 데이터는 파이프라인·합성 변형 강인성 실험용이며 실제 표절 판정 성능이 아닙니다.
- safe_arranged 라벨은 독립 검증되지 않아 임계값 적합에서 제외하고 별도 보고합니다.
- 파일명이나 위치를 바꾸면 manifest의 경로도 갱신해야 합니다.

전체 설명과 지표는 저장소 루트 MENTORING_GUIDE.md를 참고하세요.
