# Layer 2 데모 정책 제안

이 설정은 2026-09-30 그룹 분리 실험의 데모 제안입니다. 표절 확률이나 법률 판정으로 설명하지 않습니다.

## 후보 수

- 내부 검색: CLAP Top-5.
- 검토 화면: 재정렬 후 Top-3.
- 90개 합성 양성에서 원곡 포함률은 Top-3 80/90=88.9%, Top-5 85/90=94.4%. 두 후보를 더 보아 원곡 5건을 추가로 찾았습니다.
- seg_top3는 후보 곡 수가 아니라 점수를 만들 때 평균할 비중첩 매칭 구간 최대 3개를 뜻합니다.

## 점수와 처리

점수는 seg_top3_centered입니다. 기준 임베딩 평균을 제거하고 정규화한 뒤 가장 강한 비중첩 구간 최대 3개를 평균합니다. 이 값을 원시 CLAP 점수에 적용하지 마세요.

| 점수 | 상태 | 처리 |
|---|---|---|
| >= 0.894406 | HOLD | 사람 검토·정산 보류. Layer 2만으로 업로드 자동 거절하지 않음 |
| >= 0.856638, < 0.894406 | WARN | 등록 허용, 후보와 위험 지표 표시 |
| < 0.856638 | PASS | Layer 2 유사도 경고 없이 진행 |

Layer 1은 정확 지문 중복이 확인될 때 409로 업로드를 거절합니다.

홀드아웃 양성 32개·정상 119개에서 HOLD 양성 검출률 78.1%, 정상 HOLD 오탐률 5.04%; WARN 이상 양성 검출률 87.5%, 정상 WARN 이상 오탐률 18.5%였습니다. 두 목표를 동시에 충족하지 않았고 실제 재연주 평가도 아닙니다. 실제 편곡/재연주 양성과 검증된 정상 대조곡을 추가해 다시 보정해야 합니다.
