# 정책AI 발표 산출물

## 최종 발표 파일

- `정책AI_최종발표_멘토링반영_20261104.pptx` — 15장 본문 + 4장 부록의 최종 발표용 PPT
- `발표대본_15분_멘토링반영.md` — 슬라이드별 시간, HTML 시연 클릭 순서, 예상 질문 답변

## 변경 범위

이번 브랜치는 발표 자료의 UI·구성·문구만 다룹니다. 데이터, 분석 코드, 모델, 사람 검수 판정, 집계 기준, 평가 수치, 점수 산식은 수정하지 않았습니다.

## 멘토링 반영 방식

첨부된 멘토링 문서는 Track-AI 음악 프로젝트에 관한 문서이므로, 정책AI 분석 결과에 해당 문서의 기술 수치나 판정 기준을 이식하지 않았습니다. 대신 다음 발표 품질 원칙만 반영했습니다.

- 내부 현황 보고서가 아닌 15분 피칭 덱으로 재구성
- 템플릿·폰트·색상 체계 통일
- 플레이스홀더·내부 자문 문구 제거
- 구현 범위와 한계를 명확히 분리
- 과장 없는 검증 결과 및 향후 검증 과제 제시
- 데모의 질문·클릭 흐름을 사전에 고정

## 검수

PowerPoint로 19개 슬라이드를 PDF로 렌더링해 레이아웃을 확인했으며, 모든 도형이 슬라이드 경계 안에 있습니다. 검수용 PDF와 PNG는 로컬 검수 산출물로만 생성했으며 최종 발표 파일에는 포함하지 않았습니다.
