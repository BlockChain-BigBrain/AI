## HTML 시연 클릭 순서 (90초)

1. 이슈 선택에서 `인구감소·지역소멸`을 선택한다.
2. 지역별 막대/표에서 `충남`을 클릭해 해당 지역의 검토 우선순위와 관측 흐름을 강조한다.
3. 참조 그래프에서 `충북 → 충남` 선을 클릭한다. 방향은 ‘출처 지역 → 참조한 의회’임을 말한다.
4. 연결된 근거 카드에서 `2025-02-19`, 회의록명, “충북 등을 벤치마킹…” 원문을 보여 준다.
5. 참조 가중치 슬라이더를 조작해 순위가 바뀔 수 있음을 보여 준다. “예측값이 아니라 검토 순서가 바뀌는 것”이라고 명확히 말한다.
6. 마지막으로 화재예방 이슈로 한 번 전환해 동일한 탐색 흐름이 6개 이슈에 적용됨을 보여 준다.

브라우저 오류가 나면 전체 화면 캡처 또는 실행 영상을 열고, 같은 순서를 말로 따라간다. 오류 해결을 시도하며 시간을 소모하지 않는다.

## 예상 질문과 답변

### 왜 중앙값/기본 가중치 모델을 선택했나?

기본값은 특정 사례에 맞춘 최적화 결과가 아니라, 코드에 이미 고정된 S·I·T·R·C 가중치다. 사용자가 참조를 얼마나 중시할지에 따라 순위가 달라질 수 있으므로, 기본값 하나를 ‘정답 모델’로 주장하지 않고 슬라이더로 민감도를 확인하게 한다.

### PLS 실험의 의미는 무엇인가?

PLS는 변수 간 공통 구조를 탐색하는 보조 실험으로만 해석한다. 채택 라벨이나 시간 외부검증이 없는 상태에서 예측 성능이나 인과적 효력을 주장하는 근거로 쓰지 않는다. 본문에서는 핵심 결론으로 사용하지 않고, 필요 시 부록에서 탐색적 분석으로 설명한다.

### 참조 화살표가 실제 정책 확산을 뜻하나?

아니다. 화살표는 회의록에서 확인한 명시 참조 또는 시간 선후 단서를 ‘출처 지역 → 참조한 의회’로 구조화한 것이다. 실제 확산을 주장하려면 조례·예산·시행 시점 같은 별도의 외부 라벨과 시간 외부검증이 필요하다.

### 86.7%는 전체 모델 정확도인가?

아니다. 이슈별 FTS5 Top-10, 총 60건 표본에서 사람 검수로 관련 판정된 52건의 Precision@10이다. 재현율은 전수 정답 집합이 없어 측정하지 않았고, 수정 후 규칙의 독립 새 표본 평가는 다음 과제로 남겨 두었다.
